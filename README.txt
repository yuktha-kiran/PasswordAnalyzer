AI-Based Password Security Analyzer
=================================

1. Open a terminal in this folder.
2. Install dependencies:
   pip install -r requirements.txt
3. Start the app:
   python app.py
4. Open the local address shown in the terminal (usually http://127.0.0.1:5000).

Note:
This first version contains the complete UI and a transparent rule-based security analysis.
The next development step is to replace/augment the analysis engine with a trained ML model
so the project can demonstrate an actual AI prediction for the college submission.
